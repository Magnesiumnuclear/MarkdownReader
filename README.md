# Markdown 閱讀器

專為 Windows 打造的輕量級 Markdown 閱讀器。雙擊 `.md` 檔案即可用 GitHub 風格排版閱讀，具備無邊框視窗、自訂標題列、多分頁、深淺色主題與釘選最上層。再雙擊其他 `.md` 會開在同一個視窗的新分頁。

---

## 功能

| 分類 | 內容 |
|------|------|
| 開檔 | 接收 Windows 傳入的命令列路徑、`Ctrl+O` 選檔、拖放檔案到視窗；**一次可開多個**（檔案總管多選、拖放多個、命令列多個路徑；`Ctrl+O` 一次挑一個），只渲染看得到的那一個，其餘等切過去才載入；空白分頁可直接 `Ctrl+V` 貼上 Markdown 原始碼立刻排版 |
| 副檔名 | `.md`、`.markdown`、`.mdown`、`.mkd`、`.mkdn`、`.mdtxt`（這六個會被註冊成檔案關聯）；拖放與 `Ctrl+O` 另外接受 `.txt` |
| 安裝 | 安裝檔（每使用者、免系統管理員、關聯指向原生轉交器、可就地升級與乾淨反安裝）與可攜版 zip：先 `.\build.ps1 -OneDir`，再 `.\build.ps1 -Installer`（後者不重新打包，另需 Inno Setup 6） |
| 排版 | GitHub 風格 CSS、程式碼語法高亮、表格、任務清單、註腳、定義清單、刪除線、裸網址／`www.` 網域／電子郵件自動變成連結（比照 GitHub：結尾標點不算、程式碼裡的不動）、Mermaid 流程圖與序列圖（內嵌畫出）、圖片（相對路徑以文件所在資料夾為基準、過寬自動縮到視窗寬度、載不到時顯示帶 alt 與原始路徑的佔位） |
| 視窗 | 無邊框 + 自訂標題列、拖曳移動（保留 Aero Snap）、四邊四角縮放、雙擊最大化 |
| 錄影隱藏 | 標題列釘選鈕旁的攝影機鈕：按下後錄影、截圖、螢幕分享（OBS、Teams、Snipping Tool、PrintScreen 等）都擷取不到本程式的視窗，你自己的螢幕照常看得到——適合錄影或分享螢幕時把講稿、筆記留在畫面上。所有視窗一起切換，設定會記住；需要 Windows 10 2004 以上，舊版 Windows 只能讓錄到的視窗變成一塊黑 |
| 閱讀 | 深淺色主題切換、字級縮放、`Ctrl+F` 搜尋並高亮符合項（總數照實顯示，超過 2000 筆時只高亮目前位置鄰近的，計數列會註明；可切換區分大小寫／全字；連 Mermaid 圖表裡的字都找得到；搜尋列是浮動面板，可拖到任何位置）、狀態列資訊 |
| 設定 | 覆蓋式設定面板（`Ctrl+,`）：語言、主題模式、字級、行高、內文寬度，以及五個行為開關（存檔自動重載、釘選最上層、顯示狀態列、外部連結開啟前詢問、還原上次分頁），一鍵恢復預設 |
| 主題 | 預設跟隨 Windows 深淺色設定並即時同步，也可手動鎖定淺色或深色 |
| 語言 | 繁體中文 / English，預設跟隨系統；在設定面板（`Ctrl+,`）「外觀」區的**第一列**切換，切換後所有開著的視窗立刻更新 |
| 分頁 | 多分頁閱讀、中鍵關閉、分頁列可橫向捲動；「＋」開一個空白分頁（開檔用標題列的資料夾鈕或 `Ctrl+O`）；可選擇記住上次開著的分頁；貼上的分頁關閉（或關視窗）時會問要不要存成檔案，存好就變成一般的檔案分頁 |
| 拖曳 | 比照瀏覽器：分頁列內拖曳重排、拖出去變成新視窗、拖到另一個視窗合併；拖曳時有半透明縮影、插入位置指示線與「放開會發生什麼」的預告。目標視窗的分頁列被**本程式的其他視窗**蓋住也能合併——它會先自己疊到前面（蓋住它的若是釘選最上層的視窗，會暫時把目標也置頂，放開後還原）；被**別的程式**的視窗蓋住則不併，看不到的分頁列不接受放置 |
| 單一實例 | 再雙擊 `.md` 會開在既有視窗的新分頁，而不是另開一個程式 |
| 便利 | 釘選最上層、存檔後自動重載並保留閱讀位置、本機 Markdown／文字連結開在新分頁（其他本機檔案交給系統預設程式開啟）、點狀態列的路徑可在檔案總管中選取該檔、滑鼠移到連結上即在狀態列顯示目標 |
| 穩健 | 多重編碼偵測（BOM：UTF-8／16／32；無 BOM 時依序試 UTF-8、cp950、Big5、GBK、UTF-16，都不成才退回 latin-1 並在狀態列標示「可能不正確」）、檔案鎖定重試、友善錯誤頁 |

外部連結一律交給**系統預設瀏覽器**開啟，閱讀區內不會載入任何網頁；設定面板可開「開啟前詢問」，點下去會先跳確認。

## 快速鍵

| 按鍵 | 功能 |
|------|------|
| `Ctrl + O` | 開啟 Markdown 檔案（開在新分頁） |
| `Ctrl + T` | 開一個空白分頁（等同分頁列「＋」的主區域） |
| `Ctrl + V` | 在空白分頁貼上 Markdown 原始碼，立刻排版顯示；這種分頁關閉時會問要不要存成 `.md`（選不儲存後仍可用 `Ctrl + Shift + T` 找回） |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 下一個／上一個分頁（`Ctrl + PgDn` / `PgUp` 同義） |
| `Ctrl + 1` … `Ctrl + 8`、`Ctrl + 9` | 跳到第 1…8 個分頁；`Ctrl + 9` 跳到最後一個 |
| `Ctrl + Shift + T` | 重開剛關掉的分頁（每個視窗記最近 10 個，插回原位、捲動位置也還原；拖到別的視窗的不算關閉） |
| `F5` / `Ctrl + R` | 重新載入目前檔案 |
| `Ctrl + F` | 文件內搜尋（`Enter` 下一個、`Shift+Enter` 上一個、`Esc` 關閉） |
| `Alt + C` / `Alt + W` | 搜尋列開著時：切換「區分大小寫」／「全字拼寫相符」 |
| `Ctrl + ,` | 開啟／關閉設定面板 |
| `Ctrl + D` | 切換深色／淺色主題（會鎖定，不再跟隨系統） |
| `Ctrl + P` | 切換視窗釘選最上層 |
| `Ctrl + +`（或 `Ctrl + =`）/ `Ctrl + -` / `Ctrl + 0` | 放大／縮小／重設字級 |
| `Ctrl + /` | 顯示或隱藏底部狀態列 |
| `Alt + 左方向鍵` | 回到上一篇文件 |
| `F11` | 切換最大化 |
| `Ctrl + W` | 關閉目前分頁；只剩一個分頁時關閉視窗 |
| `Esc` | 先關搜尋列或設定面板；都沒開時同 `Ctrl + W`（關目前分頁，只剩一個時關視窗） |

視窗幾何、主題、字級與釘選狀態會自動記住，下次開啟時沿用；狀態列的顯示與否、設定面板裡的每一項、搜尋的比對選項也一樣。

## 安裝與執行

```bash
py -3.13 -m pip install -r requirements.txt
```

```bash
py -3.13 main.py sample.md
```

不帶參數執行會顯示歡迎頁。

> **注意**：如果系統 PATH 上有 MSYS2 或其他 Python，直接打 `python` 可能會抓到沒有安裝 PyQt6 的版本。請一律使用 `py -3.13`。

## 設定成 `.md` 的開啟程式

三種取得方式，擇一：

| 方式 | 怎麼做 | 檔案關聯 |
|---|---|---|
| **安裝檔** | 執行 `dist\MarkdownReader-Setup-<版本>.exe`（每使用者、免系統管理員） | 安裝時自動指向轉交器，反安裝時還原 |
| **可攜版 zip** | 解壓到任何位置。zip 裡附的 `portable.txt` 留在 exe 旁邊，設定與錯誤紀錄就存在旁邊的 `data` 資料夾，拔掉隨身碟不留痕跡；刪掉它就回到一般模式（登錄檔） | `py -3.13 tools/install_association.py --target "<解壓位置>\MarkdownOpen.exe"` |
| **原始碼自己打包** | `.\build.ps1 -OneDir` | `py -3.13 tools/install_association.py`（無參數會自動挑 `dist` 裡開檔最快的目標） |

`install_association.py` 只寫入 `HKCU\Software\Classes`，不需要系統管理員權限，
`--uninstall` 可完整還原。**安裝檔與這支腳本不要並用**：兩邊都會寫同一個 ProgID，
反安裝時會互相清掉對方的登錄值。

Windows 10/11 以 **UserChoice** 雜湊保護預設程式設定，第三方程式無法單靠寫入登錄檔
強制指定。做完上面任一種之後，手動指定一次即可：

> 右鍵點 `.md` 檔 → 開啟檔案 → 選擇其他應用程式 → 勾選「一律使用此應用程式」

關聯目標的優先序與各自的開檔速度、安裝檔的設計，見 [docs/07-打包與發布.md](docs/07-打包與發布.md)。

## 已知限制

- 不支援圓角、陰影、HTML `<details>` 與 GFM 警示區塊（`> [!NOTE]`）。Mermaid 只支援 flowchart 與 sequence diagram 的子集（見 [docs/02-Mermaid.md](docs/02-Mermaid.md)）。若日後需要完整保真度，唯一解是改用 `QWebEngineView`（exe 會增加約 150MB）；渲染層已隔離在 `document.py`、`qt_html.py`、`app/mermaid/` 與 `browser.py`（`viewer.py` 只負責調度），替換成本不高。
- 無邊框視窗不支援 Windows 11 的 Snap Layouts（滑鼠停在最大化鈕上跳出的版面選單），那需要攔截原生 `WM_NCHITTEST` 訊息。
- 「還原上次分頁」在多視窗下只記住最後關閉的那個視窗（每個視窗關閉時都會覆寫同一份紀錄，最後寫的贏）。要完整還原多個視窗需要另一套session 格式，目前不做。
- **還原成最大化之後，第一次點還原鈕沒有反應，要點第二次。**「一開始就以最大化
  顯示」的視窗沒有可回復的一般幾何，Qt 的 `showNormal()` 因此第一次不生效
  （純 Qt 的無邊框視窗也一樣，與本程式的實作無關）。可靠的修法是先以一般大小
  顯示、下一個事件回合才最大化，但那會讓每次啟動閃一下（實測約 114 ms），
  兩害相權之下維持現狀。
- 監聽端忙到接不下新連線時（例如正在渲染一份大檔），轉交會重試最多約 3 秒，通常只是分頁晚一點出現；真的重試到超時才會退化成另外開一個視窗。已經寫進管道的資料不會遺失，對方有空就會讀到。

## 疑難排解

| 狀況 | 處理方式 |
|---|---|
| **改了程式，雙擊開起來還是舊的** | 編到了另一個產物。確認關聯指向哪個版本，用對應的 `build.ps1` 或 `build.ps1 -OneDir`（見 [docs/07-打包與發布.md](docs/07-打包與發布.md) 的「改完程式之後的重新編譯流程」） |
| **編譯失敗 `PermissionError: [WinError 5]`** | 程式還開著，執行檔被鎖住。先 `taskkill /F /IM MarkdownReader.exe` 再編譯 |
| 雙擊 `.md` 跳「找不到應用程式」 | 關聯指向的檔案被刪掉或搬走了。重新編譯回原路徑即可，不需要重新註冊 |
| **`.md` 圖示變白紙、雙擊完全沒反應** | `dist` 裡的 `MarkdownOpen.exe` 不見了——多半是繞過 `build.ps1` 直接跑 PyInstaller，資料夾版的 COLLECT 會把整個目錄刪掉重建。重跑 `build.ps1`，或從 `build\cmake\release\` 複製回去 |
| 編輯 `build.ps1` 後出現 parser error、中文變亂碼 | `.ps1` 必須存成 **UTF-8 with BOM**。PowerShell 5.1 讀沒有 BOM 的檔案會當成 ANSI（繁中系統為 cp950），中文會壞掉並讓字串沒有結尾 |
| 打包後圖示全部空白 | 預設走 `build.spec`：確認 `datas` 有 `("assets", "assets")` 與 `("languages", "languages")`、`hiddenimports` 有 `PyQt6.QtSvg`。走純 CLI 形式則是 `--add-data "assets;assets" --add-data "languages;languages" --hidden-import PyQt6.QtSvg` |
| 程式沒有畫面就消失 | 查看 `%LOCALAPPDATA%\MarkdownReader\error.log`，未攔截的例外都會寫在這裡 |
| 雙擊 `.md` 仍由其他程式開啟 | Windows UserChoice 優先，請用「開啟檔案 → 選擇其他應用程式 → 一律使用此應用程式」指定一次 |
| 中文顯示成亂碼 | 狀態列會顯示實際判定的編碼；若標示為 `latin-1（可能不正確）`，代表該檔案編碼超出偵測範圍 |
| 程式碼區塊沒有高亮 | 確認已安裝 `Pygments`（`py -3.13 -m pip install Pygments`） |
| 關掉程式後雙擊 `.md` 沒有反應、或新開的視窗立刻消失 | 單一 exe 的**本體行程**可能還活著佔著管道（用工作管理員砍掉啟動器不會連本體一起砍）。`taskkill /F /IM MarkdownReader.exe` 會一次清乾淨 |
| 雙擊 `.md` 開了新視窗而不是新分頁 | 兩個視窗來自**不同路徑**的執行檔（例如單一 exe 與資料夾版各開一個）時，各自都會是「第一個實例」。統一用同一個產物即可 |
| 雙擊 `.md` 後分頁出現但內容空白 | 這是收方在資料進緩衝區前就判定連線結束。若自行改過 `app/single_instance.py`，確認 `_on_connection` 補讀那段還在 |
| 執行安裝檔或程式時跳出「Windows 已保護您的電腦」 | 安裝檔與本體都**未簽章**，SmartScreen 會攔「未知的發行者」。按「其他資訊 → 仍要執行」即可 |
| 多選很多檔案時，檔案總管先跳出「確定要開啟這麼多檔案嗎」 | 那是 Windows 自己的防呆（門檻由 `MultipleInvokePromptMinimum` 決定，預設 15），不是本程式跳的。**刻意不去改它**：那個設定是整個系統共用的，也是誤選兩百個檔案時唯一的保護。按確定就會照常全部開成分頁 |
| 多選開啟後只看到其中一個檔案 | 這是刻意的：同一批只渲染你看到的那一個，其餘是分頁列上的**延後分頁**，切過去才讀檔。分頁列上檔名都在，點一下就開 |
